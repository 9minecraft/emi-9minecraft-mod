## About this mod

EMI 9minecraft Mod gives you a helpful side panel that shows every item and recipe in the game. You can click on any block or tool to see exactly how to make it or what it is used for. The mod makes it simple to plan big crafting projects by showing you a tree of all the parts you need. It also lets you search for specific things using names or tags so you never get stuck wondering how to craft something again.
